# Data Directory

This directory contains all the data for this project.

The data directory is organized into two main categories: data collected by The University of Sydney and external data from other contributors. The file structure reflects this division.

```python
-external # external contribution
-metadata # metadata (e.g. manikin info, pcs product info, experiment info)
-others
-usyd # The University of Sydney's data

`pcsdatabase.csv` is the main database file that contains all the infomation of this databas.
```
